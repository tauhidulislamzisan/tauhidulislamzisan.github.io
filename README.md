# Tauhidul Islam Zisan: personal academic website

Source for <https://tauhidulislamzisan.github.io>, built with [Jekyll](https://jekyllrb.com/) and the [al-folio](https://github.com/alshedivat/al-folio) template. It deploys through GitHub Actions to the `gh-pages` branch.

- `_pages/about.md`: home page
- `_data/cv.yml`: CV page
- `_bibliography/papers.bib`: publications
- `_projects/`: projects
- `_news/`: news items
- `_data/socials.yml`: social links
