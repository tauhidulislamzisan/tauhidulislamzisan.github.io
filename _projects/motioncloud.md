Front-end developer on Motion Cloud, a cloud application with a web client, a desktop build and a Java back end.

- **Stack:** React 18, TypeScript, Redux Toolkit, Ant Design, React Hook Form with Yup, Axios, SCSS, and a Tauri desktop wrapper; the back end is a Java Maven service with OpenAPI docs.
- **Scope:** built the module management, type management and support screens, the Redux state slices, API service layer and typed API models behind them.
- **Delivery:** worked in a shared repository that includes build and deploy scripts for the frontend and backend.
