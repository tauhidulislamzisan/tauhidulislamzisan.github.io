**When:** May 2026 to present · **Role:** Co-founder · **Site:** [flashdsm.com](https://flashdsm.com)

**Stack:** Vite/React editor, FastAPI, PostgreSQL, MCP, pnpm TypeScript monorepo, Docker.

Flash DSM is a design-system product that gives AI coding tools a token and component rules layer. It encodes design tokens and component rules as a machine-readable "design genome", so AI-assisted UI generation stays consistent.

**My role**
- Co-building the product.
- Contributing to the TypeScript monorepo, including MCP-oriented interfaces, editor and plugin integrations, and design-token exports.
