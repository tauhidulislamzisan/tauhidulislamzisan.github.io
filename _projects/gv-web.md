Contributing developer on the GoaldenView web app between January and October 2024, working in a shared Next.js codebase.

- **Stack:** Next.js 14 (App Router) and TypeScript, tRPC, Prisma with MySQL, Clerk authentication, Tailwind CSS and MUI, Recharts, Stripe, installable as a PWA.
- **Features built:** player, club and league pages, a player comparison view, ranking tables with rank-change and score-trend views, league pages with formation views, and user profile pages with followed players and clubs.
- **Data upkeep:** scripts and updates for weekly ranking releases, player positions and photos, and club and league data.
