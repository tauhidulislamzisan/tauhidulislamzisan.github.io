**When:** January 2024 to March 2026 · **Role:** Full Stack Developer (part-time, remote; senior developer on internal systems) · **Organisation:** GoaldenView

**Stack:** Python, FastAPI, Next.js, AWS S3, Docker, GitLab CI/CD, Stripe, Mailchimp.

The GoaldenView Popularity Ranking (GVPR) is a ranking pipeline and set of product surfaces for weekly footballer popularity across leagues.

**My role**
- Built a rank generator implementing the GVPR pipeline in Python, combining live football data sources for English Premier League player rankings.
- Built features that publish weekly rankings from pipeline outputs, across the FastAPI backend and the Next.js web frontend.
- Integrated Stripe subscriptions and configured Mailchimp; built a standalone application.
- Wrote developer, API and deployment handover documentation (GitLab CI/CD, Docker, AWS S3). Native mobile apps were in progress and are not claimed as shipped.
