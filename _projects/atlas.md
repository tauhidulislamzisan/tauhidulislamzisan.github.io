**When:** July 2025 to present (part-time, then full-time from November 2025) · **Role:** Full-Stack AI Developer and Development Team Lead · **Organisation:** Atlas Sweden AB / Atlas Group

**Stack:** FastAPI, PostgreSQL, SQLAlchemy/Alembic, Celery, Redis, React/TypeScript with Vite, Tauri (desktop functionality), Docker and Docker Compose.

ATLAS is a Test Management System for planning, execution, analysis and reporting. It has four modules: **Planner**, **Live**, **Analysis** and **Reports**. It also includes **Hermes**, an in-execution communication feature for talking with participants during test execution.

**My role**
- Lead development, covering application architecture, repository organisation and delivery workflows.
- Containerised deployment with Docker and Docker Compose; review and merge changes, including database migrations and shared components.
- Designing repository-guided AI-assisted development workflows for non-engineering contributors.
- Developing controlled LLM tool-call integrations for the product.
