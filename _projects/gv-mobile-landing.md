Two small prototypes for GoaldenView, each built mostly alone.

- **Mobile app (2024):** a React Native and Expo app (Expo Router, NativeWind, TanStack Query) started from an open-source starter, with onboarding and login screens and sortable, filterable ranking tables for players and clubs. It rendered bundled ranking data rather than a live API.
- **Landing page (2026):** a React, Vite and Tailwind CSS marketing page with hero, ranking preview, features, FAQ and an application form for professional early-access users.
