Smart-contract development for a metaverse game project with two ERC-20 based tokens: EXO, a governance token, and GCRED, an in-game token earned by staking EXO.

- **Contracts:** upgradeable Solidity contracts (OpenZeppelin proxies) for the two tokens, staking rewards, governance voting, a token sale, a cross-chain token bridge, planet, bonus and game-asset NFTs, an NFT bridge, and a marketplace with coordinate contracts.
- **Tooling:** Hardhat with numbered test suites covering each contract (15 test files), solhint and Prettier for Solidity, and deploy and upgrade scripts for a local network, EVM chains and VeChain.
- **Scope:** development only; no audit results or deployment outcomes are claimed here.
