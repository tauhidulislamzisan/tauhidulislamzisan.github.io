Main developer of an internal administration dashboard and visual logic builder for Bock Lighting, built at Cocoon.

- **Stack:** React 17, Material UI, React Router.
- **Admin screens:** list, add and edit pages generated from the content model's entity and bundle definitions, with a library of form field types (text, numbers, media, references, colour and code editors, rich text).
- **Builders:** a drag-and-drop spec-sheet designer with PDF preview, a part builder and a rule/logic builder, and a screen for managing the front-end search records.
